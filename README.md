## 설치 및 실행 방법
```bash
git clone https://github.com/sg1315/KinderBridge.git
cd KinderBridge 

# 프론트
cd front
npm install
npm start

# 백엔드
cd back/kinder
./gradlew bootRun
```
## 주요 기능
- 회원가입 및 로그인 (JWT 기반)
- 교사 건강 관리 지원
- 아동 정보 관리
- 아동 생활 및 활동 기록
- 게시판과 채팅을 통한 학부모와의 소통
- 일정 관리 ,출석 체크등의 교사 업무 지원

## 부가 기능
- 전화번호 본인인증 (coolsms)
- React Calander를 이용한 교사의 일정관리
- 교사의 개인 문서 저장 및 다운
